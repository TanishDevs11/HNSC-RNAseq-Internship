## Caption notes

- **Figures 1–3:** the plot subtitles read "Genes: 56600", because the code prints the row count of the matrix before filtering. Per the report, the pre-correction PCA (Figure 1) was computed on the 52,568 genes retained after filtering, and the post-correction PCAs used all 56,600 corrected genes.
- **Figure 4:** `DESeq2::plotMA` colours points by adjusted p-value only (default `alpha = 0.1`). The blue colouring does not apply the |log2FC| ≥ 2 cut-off.
- **Figure 7:** the 20 pathways shown are the 20 with the smallest adjusted p-values (the script orders by `p.adjust`). Bar length is the gene count.
